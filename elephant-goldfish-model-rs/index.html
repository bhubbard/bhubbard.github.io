Elephant-Goldfish Model (Rust Port)

Elephant-Goldfish Model (elephant-goldfish-model-rs) is a pure-Rust Spec-Driven Development (SDD) engine and deterministic multi-runtime plugin packager that pairs full-history "Elephant" orchestrators with zero-prior-context "Goldfish" subagents. It compiles and validates Google's 7 EGM workflows, 9 review personas, and reproducible Claude Code and OpenAI Codex plugin bundles into a single native binary with zero C/FFI dependencies.

7 Skills / 9 Agents
Brainstorm, Draft, Review, Loop, Resolve, Drift, Bootstrap
100% Byte-Exact
Deterministic PKWARE ZIP & FIPS 180-4 SHA-256
6 Offline Suites
Frontmatter, Links, Tables, Load Limits, Scenarios, Harnesses
23.8× Faster
Native Rust CLI vs Python Packaging & Validation

Dual Goldfish A/B Findings Input

Isolated Goldfish reviewers (Reviewer A & Reviewer B) inspect target line spans without shared conversation bias. The Synthesizer merges overlapping ranges, escalates severity, and emits canonical [path:Lstart-end](path#Lstart-Lend) links.

LensAdversarial Challenge

            
            
              
1. Prior Art TrapDoes this already exist in the codebase, stdlib, or mature dependency?

              
2. SimplificationWhat happens if we cut 50% of components while keeping 80% of value?

              
3. Scale InversionWhere does this break at 100× load or become over-engineered at 0.01×?

              
4. Failure ModesHow does the system recover when disk or subagents fail mid-flight?

              
5. Cost of ChangeWhich abstractions lock us into irreversible schema commitments?

              
6. Dependency AuditWhich external tools, runtimes, or ambient assumptions can be dropped?
