seexpr-rs — Pure Rust Port of Walt Disney Animation Studios' SeExpr Expression Language

seexpr-rs is a zero-allocation Rust bytecode compiler and virtual machine for Walt Disney Animation Studios' SeExpr procedural expression language. Artists and technical directors use it to author real-time procedural shaders, Perlin/Voronoi noise textures, and particle geometry attributes at 80+ million evaluations per second.
